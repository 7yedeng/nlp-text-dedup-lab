# 中文文本特征表示与内容重复理解（NLP 实验一）

围绕「文本特征表示 → 文本相似度 → 内容重复识别」这条主线，用**真实抓取的中文新闻语料**完成 4 组实验，
全部指标可复现、结论可验证：TF-IDF 特征表示与相似检索、MinHash + LSH 短文本去重、
预训练词向量（腾讯 AI Lab）文档表示与聚类、TF-IDF 加权 SimHash 网页新闻近似重复检测。

- 语料：**全部真实抓取**（网易滚动新闻接口 / 新浪滚动新闻 API），共 2 579 条标题 + 170 篇正文
- 结果：4 个实验脚本均输出 `out/*_results.txt` 指标 + `out/figures/*.png` 可视化
- 报告：`out/<成员一姓名>+<成员一学号>+第1次实验报告.docx`（含原理、白底代码截图、P/R/F1 表、可视化、学习笔记）
- 复现：所有随机过程固定随机种子（`seed=42`），同一环境下结果确定
- 审计：`out/AUDIT_NOTES.md` 记录了复刻复现的逐项核查与 8 处修正（含修正前后对照）

> **本次修订说明**：本版本在复刻验证中做了一次完整审计，修正了 8 处问题
> （元信息解析、TF-IDF 大小写回查、语料规范化、金标准分层、P/R 空分母口径、批量计时实验设计等），
> 并追加了「按唯一词加权」的消融实验。**原始落盘结果备份在 `out/_baseline_original/`**，
> 可逐行对照。下表为修订后的指标。

## 一、实验内容与结果速览（修订后）

| 实验 | 方法要点 | 关键结果 |
| --- | --- | --- |
| 一(1) TF-IDF 文本特征表示 | jieba 分词 + 停用词，`TfidfVectorizer(max_features=1000, ngram_range=(1,2))`，余弦相似度 Top-10 | 语料 2 579 → 规范化去重后 **2 576** 条 → 矩阵 `(2576, 1000)`；Top-10 全部是模板化近似重复（10 对相似度均 = 1.0000） |
| 一(2) MinHash + LSH 短文本去重 | 词级 1+2-gram shingle；MinHash 签名 k=128（`h_i(x)=(a_i·x+b_i) mod (2^61-1)`）；LSH band 分桶 | MinHash 估计 Jaccard 平均绝对误差 **0.0064**（最大 0.0239）；分层口径下阈值 ≥0.4 时精确与近似均达 P=R=F1=**1.000** |
| 二(1) 预训练词向量 | 腾讯 AI Lab 中文词向量（Gensim `KeyedVectors`）→ 语义推理 + 12 组词对相似度 + 词向量平均池化文档向量 + PCA/t-SNE + KMeans | 143 613 词 × 200 维；词表覆盖率 **89.41%**；类比推理 6 组命中 3 组；类内相似度 0.9081 > 类间 0.7993；KMeans（K=3）**Purity 0.9400 / ARI 0.8319** |
| 二(2) 加权 SimHash | 20 篇网页新闻，64 位指纹，TF-IDF 加权 + 停用词降权，海明距离 ≤ 3 判重，与等权 SimHash 对比 | **加权：P=1.000 R=0.833 F1=0.909**；等权：P=0.154 R=1.000 F1=0.267（误报 66 对） |

### 实验一(1)：TF-IDF 特征表示（[exp1_tfidf.py](exp1_tfidf.py)）

- 词频最高 20 词的平均 TF-IDF 权重柱状图：`out/figures/exp1_tfidf_top20.png`，权重最高的是「电影」（0.4560）
- 语料规范化去重：原始 2 579 条里有 3 条仅空格/大小写差异的重复标题
  （如「腾势 D9 车型 OTA 升级」/「腾势D9车型OTA升级」），分词后完全一致、余弦相似度恒为 1.0000，
  会霸占 Top-10。按「去空白 + 小写」去重后有效语料 2 576 条
- 全语料 3 316 600 个文本对：相似度均值 0.0055、P99 0.208、最大 1.000；
  ≥0.9 的有 511 对，≥0.5 的 4 859 对
- **Top-10 全部是模板化批量内容**：9 对是「微博观影团《X》北京首映免费抢票」（仅影片名不同），
  1 对是「253期X福彩3D预测奖号：X推荐」。语料中模板化标题共 218 条（8.5%）：
  彩票预测 101、竞彩/指数 40、影迷评 29、公司增减持 25、观影团抢票 24。
  仅占 8.5% 的模板内容占据了相似度最顶端，因为它们 TF-IDF 向量几乎相同
- 关于「AI」：词频 82 次、平均权重 **0.3566**，**一直在特征集内**。
  早期实现因分词保留原形而特征名被 lowercase 成「ai」，回查权重时大小写不匹配而误报为 0.0000

### 实验一(2)：MinHash + LSH（[exp1_minhash.py](exp1_minhash.py)）

6 条测试用例（`data/short_texts.txt`）。实测这 6 条用例内部有**三个相似度量级**，
因此金标准分三层（`T1-T2`=近重复 1.0000；`T1~T4` 其余对=同事件改写 0.1176~0.3077；`T5/T6`=不相关 0.0000）：

| 文档数 | 全量对数 | LSH(b=16,r=8) 候选 | LSH(b=64,r=2) 候选 |
| --- | --- | --- | --- |
| 6 | 15 | 0 | 1 |
| 50 | 1 225 | 0 | 7 |
| 200 | 19 900 | 0 | 45 |
| 500 | 124 750 | 3 | 284 |

分层口径（正样本 = 近重复 T1-T2）下的阈值影响：

| 阈值 | 精确 Jaccard (P/R/F1) | MinHash (P/R/F1) |
| --- | --- | --- |
| 0.2 | 0.333/1.000/0.500 | 0.333/1.000/0.500 |
| **0.4** | **1.000/1.000/1.000** | **1.000/1.000/1.000** |

- **「最优阈值」取决于业务对「什么算重复」的定义**：只去真重复取 0.4；要把改写稿一并收敛则取 0.1~0.2
  （该区间能召回 5/6 对改写稿且零误报）
- LSH 参数必须按目标相似度区间标定：`(b=16,r=8)` 只对相似度 ≥0.9 的文档有效，
  在真实新闻标题（两两 Jaccard 普遍 <0.3）上几乎剪掉一切；
  要高召回必须用 `(b=64,r=2)` 这类小 r 配置
- 工程上通常「LSH 粗筛候选 → MinHash 相似度回验 → 阈值判定」三段式串联

### 实验二(1)：预训练词向量（[exp2_wordvec.py](exp2_wordvec.py)）

- 语义推理（类比）：`国王 − 男人 + 女人 ≈ 王后`(0.705)、`北京 − 中国 + 法国 ≈ 巴黎`(0.686)、
  `中国 − 北京 + 伦敦 ≈ 英国`(0.769) 命中；`父亲 − 儿子 + 母亲` 返回「父母亲」而非「女儿」，
  说明词向量对**反义/性别方向的组合并不稳定**
- 文档表示：体育 / 科技 / 娱乐各 50 篇，词向量平均池化；**词表覆盖率 89.41%**
  （体育 82.63% 最低，因运动员姓名、队名多为 OOV）；类内平均相似度 0.9081 > 类间 0.7993
- PCA / t-SNE 降维可视化 + KMeans 聚类：`out/figures/exp2_wordvec_pca_tsne.png`
- 混淆矩阵（行=真实主题，列=簇 0/1/2）：科技 `[50,0,0]`、娱乐 `[0,50,0]` 被完美分开；
  **体育 `[2,7,41]` 是唯一被拆开的类**——并非「体育被整类错分到娱乐」，
  而是体育内部本身不够紧凑（人物故事、赛事花絮用词与娱乐重叠）

### 实验二(2)：TF-IDF 加权 SimHash（[exp2_simhash.py](exp2_simhash.py)）

数据集 `data/news20/`（含 `manifest.json` 分组标签）。**组内实测相似度天然分两档**：
改写簇 R1/R2 为 0.96~1.00（真·近似重复），同事件不同报道 D1/D2 仅 0.11~0.26。
因此正样本定义为**改写簇组内对（12 对）**；D3 组经复核为**标注错误**
（15 号=女子现代五项团体夺金；16/17 号=男子铁人三项摘银，分属不同事件），不计入正样本。

| 方案（距离 ≤ 3） | P | R | F1 | TP/FP/FN |
| --- | --- | --- | --- | --- |
| **TF-IDF 加权（按词元，原方案）** | **1.000** | **0.833** | **0.909** | 10/0/2 |
| TF-IDF 唯一词（消融对照） | 1.000 | 0.583 | 0.737 | 7/0/5 |
| 等权（词频） | 0.154 | 1.000 | 0.267 | 12/66/0 |

- 等权 SimHash 把「扎克伯格访谈」（R1）与国米罗马评论（R2）、佟丽娅报道（D1）、
  甚至百川智能融资（U1）都判成重复——停用词与通用词在等权累加中主导了指纹。
  **换成 TF-IDF 加权 + 停用词降权后，误报从 66 对降到 0 对**
- 「按词元累加权重」（权重随词频近似二次增长）初看可疑，但**消融实验证明它更优**：
  唯一词版召回 0.583 < 原方案 0.833，查准率同为 1.000。因此保留原设计
- 阈值扫描：加权方案 P 在阈值 0~5 全程 1.000，阈值 6 时 F1 达 0.960（R=1.000）；
  等权方案 F1 在 0~10 几乎不动（0.267~0.308），因其误报是「系统性」而非「边界性」的

  平均 TF-IDF 权重会有约 1%~4% 差异（**词表内容与词频完全一致**），报告数值以本环境为准

## 四、如何运行

```bash
# 实验一(1)：TF-IDF（约 13 秒，无需模型）
python exp1_tfidf.py

# 实验一(2)：MinHash + LSH（含批量规模计时，约 13 秒）
python exp1_minhash.py

# 实验二(1)：预训练词向量（需先准备 model/ 下的词向量文件，见下，约 60 秒）
python exp2_wordvec.py

# 实验二(2)：加权 SimHash（约 8 秒）
python exp2_simhash.py

# 重新生成报告（可选）
python tools/make_screenshots.py && python tools/build_report.py
```

四个脚本各自读写 `data/` 与 `out/`，可独立运行。

### 词向量模型准备

仓库**不包含**预训练词向量（体积过大，且作业要求不提交大型模型文件）。
实验二(1) 使用的模型为 **腾讯 AI Lab 中文词向量（轻量版，200 维，143 613 词）**，
需自行下载后转换为 word2vec 二进制格式，放置为
`model/light_Tencent_AILab_ChineseEmbedding.bin`
（脚本用 `KeyedVectors.load_word2vec_format(..., binary=True)` 加载，首行为 `143613 200`）。

> 说明：若替换为其它版本词向量，词对相似度与聚类指标会随之变化，但脚本与评估流程不变。

## 五、数据说明

| 数据 | 规模 | 获取方式 |
| --- | --- | --- |
| `data/titles.txt` | 2 579 条标题 | 新浪滚动新闻 API（`feed.mix.sina.com.cn/api/roll/get`）多频道分页聚合 |
| `data/sports/` `tech/` `ent/` | 各 50 篇 | 网易滚动新闻接口（GBK JSON）+ 详情页正文解析（requests + BeautifulSoup/lxml） |
| `data/news20/` | 20 篇 + 真值 | 由上表真实文章按规则构造：源文 / 转载（换标题）/ 轻度改写 / 中度改写 / 同事件不同报道 / 无关主题 |
| `data/short_texts.txt` | 6 条 | 人工设计：完全重复 / 轻度修改 / 中度改写 / 完全不相关 |

正文文件格式（便于机器解析）：

```
title=标题
source=来源|URL
category=类别

正文……
```

> 解析要点：元信息块与正文之间有一个空行，必须按**首个空行**切分。
> `raw.split("\n", 3)[3]` 是错的——它只切掉 3 个换行，会把 news20 的 `group=` / `rewrite=`
> 当成正文词混入文档（详见 `out/AUDIT_NOTES.md` 的 C1）。

抓取脚本仅使用公开接口与浏览器 UA 标识，未使用任何账号、Cookie 或密钥；
数据仅用于课程实验，版权归原媒体所有。

## 七、已知限制与可改进方向

- 停用词表为内置常用词表（偏薄，未过滤「已/后/人/大/期/新」等虚词），不同语料下可能需调整；
  但扩充会改变全部实验口径，故本版本未动
- 实验一(2) 的分层金标准仅基于 6 条人工用例，统计意义有限；生产环境应在更大标注集上标定阈值
- 实验二(1) 的词向量平均池化忽略词序与词重要性，且轻量版词表对专有名词不友好
  （体育类覆盖率仅 82.63%）；可对比 TF-IDF 加权池化 / SIF 加权，或换用完整版词表
- 实验二(2) 的真值标签由构造规则生成，属于「规则真值」而非人工双盲标注；
  D3 组已发现标注错误，其余分组建议人工复核一遍
- SimHash 召回率 0.833 的缺口来自中度改写样本：64 位指纹对长文改写不够敏感，
  可考虑分段 SimHash 或多指纹组合
- 语料中模板化标题占 8.5%，会主导 Top-10 相似对；若要研究「新闻事件重复」，
  建议先按模板特征过滤或分桶
