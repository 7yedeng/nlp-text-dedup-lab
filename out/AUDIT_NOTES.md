## 二、已修正的缺陷

### C1【严重·正确性】元信息解析错误：`group=` / `rewrite=` 被当成正文

**位置**：`exp2_simhash.py: load_news20()`、`exp2_wordvec.py: load_docs()`
（初版代码均为 `f.read().split("\n", 3)` 后取 `lines[3]` 作为正文）

**问题**：`split("\n", 3)` 只切掉 3 个换行，而元信息块与正文之间还有一个**空行**，
所以第 4 段实际内容包含了剩余元信息：

```
doc 01 的 lines[3] 开头 = 'group=R1\nrewrite=\n\n\n智东西\n编译 陈骏达…'
            正确正文开头 = '智东西\n编译 陈骏达…'
```

**影响**：`group=R1` / `rewrite=` / `category=` 这类串被 jieba 切成 `group`、`rewrite`、
`category` 等 token 混入文档，虚增词表覆盖率；若日后给 `data/sports|tech|ent` 也加上
`group=` 标注，会直接污染 150 篇主题文档向量。

**修正**：改为按**首个空行**严格切分（`raw.partition("\n\n")`），并顺便把元信息解析成 dict。

**验证**：`data/sports|tech|ent` 三个目录的文件没有 `group=` 行，因此主题文档向量结果
**不受影响**（修正前后 `(150, 200)`、类内 0.9081 / 类间 0.7993、Purity 0.9400 完全一致）；
news20 中 1~8 号文档的正文被修正干净。

---

### C2【严重·正确性】TF-IDF 权重回查时大小写不匹配，导致误判

**位置**：`exp1_tfidf.py`（Top-20 词的权重回查）

**问题**：`TfidfVectorizer` 默认 `lowercase=True`，特征名一律小写；而初版分词函数
`w.strip()` **保留了英文原形**。于是：

- 词频统计里的键是 `AI`（语料中 84 次）
- 特征集里的键是 `ai`
- `fdict` 由特征名构成 → 查 `AI` **必然落空** → 权重被写成 `0.0000`

初版报告把这个结果解释为「AI 词频高但未进入 max_features=1000 的特征集」，
**这个解释是错的**：`ai` 一直都在特征集里。

**修正**：分词阶段统一 `w.strip().lower()`，与 `lowercase=True` 对齐；并在落盘结果中
增加「进入特征集=是/否」一列，让 OOV 与「查不到」可以直接区分。

**验证（修正前后对比）**：

| 词 | 词频 | 平均 TF-IDF（修正前） | 平均 TF-IDF（修正后） | 进入特征集 |
| --- | --- | --- | --- | --- |
| AI / ai | 84 → 82 | **0.0000（误报）** | **0.3566** | 是 |
| group / rewrite | — | 混入正文 | 已剔除 | — |

### C3【中等·实验设计】语料未规范化，Top-10 被“排版差异”占满

**位置**：`exp1_tfidf.py`（语料加载）

**问题**：`data/titles.txt` 中同一标题存在仅空格差异的重复条目，例如
`腾势 D9 车型 OTA 升级` 与 `腾势D9车型OTA升级`。分词后词序列完全一致，
余弦相似度恒为 `1.0000`，在 Top-10 中霸榜。

**修正**：加载时按「去空白 + 统一小写」规范化去重，并统计移除条数。

**验证**：2579 → **2576** 条（移除 3 条，占 0.12%）。
修正后 Top-10 全部是**真实的近似重复**，并暴露出一个更值得写进报告的现象（见 §3.1）。

---

### C4【严重·金标准错误】news20 的 D3 组标注错误

**位置**：`data/news20/manifest.json`（`group=D3` 的 15/16/17 号）

**问题**：三篇被标为「同一事件」，实际内容为：

| 编号 | 标题 | 实际事件 |
| --- | --- | --- |
| 15 | 中国代表团首金来了！女子现代五项团体成功卫冕 | 女子现代五项团体金牌 |
| 16 | 中国代表队首枚奖牌，张玺瑞在亚运会男子铁三项目中夺得银牌 | 男子铁人三项银牌 |
| 17 | 中国无缘连续7届包揽亚运首金：仅差9秒摘银 | 男子铁人三项银牌 |

**15 号与 16/17 号是两个不同项目、不同运动员、不同奖牌颜色的事件**，15-16、15-17 两对
（共 2 对）作为「近似重复」正样本是错误的。

**修正**：不改动原始数据与 `manifest.json`（保持可追溯），而是在 `exp2_simhash.py` 中
把金标准拆成三层，并**同时输出两套指标**：

| 口径 | 正样本定义 | 对数 |
| --- | --- | --- |
| 初版口径 | 所有同组文档对 | 21 |
| **修正口径（推荐）** | 改写簇 R1/R2 组内对（真·近似重复） | **12** |
| 同事件不同报道（另计） | D1/D2 组内对 | 6 |
| 不相关 | D3 + U1~U3 | 0 |

**分层依据（组内词级 Jaccard 实测）**：

```
R1: 0.9961 0.9913 0.9903 0.9874 0.9903 0.9894     ← 改写簇，几乎同文
R2: 0.9920 0.9763 0.9722 0.9686 0.9722 0.9609     ← 改写簇，几乎同文
D1: 0.1637 0.1500 0.1442                          ← 同事件不同报道，文本迥异
D2: 0.2177 0.2077 0.2593
D3: 0.1565 0.1364 0.2266                          ← 且其中含不同事件
```

改写簇（0.96~1.00）与同事件簇（0.11~0.26）**完全分离**，因此把两者混入同一条 P/R/F1
必然导致召回率被系统性压低。

### C5【中等·方法学】P/R/F1 在分母为空时取 1.0

**位置**：`exp1_minhash.py`、`exp2_simhash.py` 的 `prf()`

**问题**：初版 `p = tp/len(pred) if pred else 1.0`。当模型**一对都没检出**时，
查准率被定义为 `1.0`，于是出现「没有任何预测却 F1 = 1.000」的荒谬结论
（实验一(2) 混合口径下阈值 0.0 那一行即为此情况）。

**修正**：分母为空时取 `0.0`，并让 `prf()` 同时返回 `TP/FP/FN`，
使「无预测」与「全对」在结果里不可能混淆。

---

### C6【中等·实验设计】批量计时实验的“文档”几乎相同，导致时间对比失真

**位置**：`exp1_minhash.py`（批量规模实验）

**问题**：初版用 `docs = [cases[i % 6] + f" {i}" for i in range(m)]` 造规模。
由于分词后「原文本 + 空格 + 数字」只多出一个数字 token，**同余类的文档几乎完全相同**，
于是 LSH 候选对数被极度放大（n=500 时 27640 对 / 全量 124750 对），
既不能反映真实语料的分布，也让「精确 vs 近似」的时间对比失去意义。

**修正**：改用真实 `data/titles.txt`（2576 条）前 m 条扩展规模，并同时报告
两种分桶参数 `(b=16,r=8)` 与 `(b=64,r=2)` 的真实候选对数与剪枝率。

**修正后实测（真实标题语料）**：

| 文档数 | 全量对数 | LSH(b=16,r=8) 候选 | LSH(b=64,r=2) 候选 |
| --- | --- | --- | --- |
| 6 | 15 | 0 | 1 |
| 50 | 1225 | 0 | 7 |
| 200 | 19900 | 0 | 45 |
| 500 | 124750 | 3 | 284 |

**新的、更准确的结论**：`(b=16, r=8)` 的碰撞概率 ≈ `s^128`，只适合**极高相似度**（≥0.9）；
真实新闻标题之间的 Jaccard 普遍 < 0.3，因此几乎全被剪掉。
要在 0.3~0.5 相似度区间召回候选，必须用 `(b=64, r=2)` 这类小 r 配置。

### C7【中等·金标准口径】实验一(2) 的 T1~T4 全部当作“重复”

**位置**：`exp1_minhash.py`

**问题**：初版把 T1~T4 两两全部视为重复（6 对，即“闭包”口径）。但实测：

```
T1-T2 = 1.0000   T1-T3 = 0.3077   T3-T4 = 0.1176
T1-T4 = 0.1875   T2-T3 = 0.3077
```

T1-T4 / T3-T4 只有 0.12~0.19，属「同一事件的中度改写」，与完全重复（1.00）不同量级。
混在一起统计会让阈值 0.1 处出现 F1=1.000 的“假最优”，掩盖方法差异。

**修正**：拆成三层并**同时给出两套指标**：

- 近重复（近重复正样本）：`T1-T2`
- 同事件改写（不作为正样本，另计命中数）：`T1-T3`、`T2-T3`、`T1-T4`、`T2-T4`、`T3-T4`
- 不相关：`T5`、`T6`（与 T1~T4 相似度全为 0.0000，天然间隔带）

**修正后关键结论（分层口径，正样本=近重复）**：

| 阈值 | 精确 Jaccard (P/R/F1) | MinHash (P/R/F1) |
| --- | --- | --- |
| 0.2 | 0.333 / 1.000 / 0.500 | 0.333 / 1.000 / 0.500 |
| **0.4** | **1.000 / 1.000 / 1.000** | **1.000 / 1.000 / 1.000** |
| 0.9 | 1.000 / 1.000 / 1.000 | 1.000 / 1.000 / 1.000 |

即：若要「只去真重复、不误伤改写稿」，阈值应取 **0.4** 左右；
若要「把改写稿也一并收敛」，则取 0.1~0.2，此时召回 5/6 对改写稿、零误报。

### C8【低·说明】加权 SimHash 的权重口径（经消融验证，判定为**设计选择而非缺陷**）

**位置**：`exp2_simhash.py`（`fp_w` 构造）

初版按**词元出现次数**累加 TF-IDF 权重（同一词出现 3 次则该词的 TF-IDF 权重被加 3 次），
其隐含效果是权重随词频近似**二次增长**（`TF × IDF × TF`）。

**这是否是缺陷？用消融实验回答**。新增「按唯一词加权」对照（权重只计一次）：

| 方案（修正口径，距离 ≤ 3） | P | R | F1 | TP/FP/FN |
| --- | --- | --- | --- | --- |
| **TF-IDF 加权（原方案，按词元）** | **1.000** | **0.833** | **0.909** | 10/0/2 |
| TF-IDF 唯一词（消融） | 1.000 | 0.583 | 0.737 | 7/0/5 |
| 等权（词频） | 0.154 | 1.000 | 0.267 | 12/66/0 |

**结论**：原方案召回率 0.833 明显高于唯一词版 0.583，且查准率同为 1.000。
因此「按词元累加」在本任务上**确实更优**（与经典 SimHash 用 TF 加权、重复词加强投票的直觉一致），
**保留原设计**，仅补充消融数据说明其收益，并把这个选择写进报告。

## 三、修正后暴露出的两个新现象（建议写进报告）

### 3.1 语料被模板化内容污染，Top-10 全是“模板近似重复”

修正 C3 后，Top-10 相似文本对**全部**是模板生成的批量内容：

```
微博观影团《毕正明的证明》北京首映免费抢票  ↔  微博观影团《浪浪山小妖怪》北京首映免费抢票
微博观影团《毕正明的证明》北京首映免费抢票  ↔  微博观影团《刺杀小说家2》北京首映免费抢票
…（同一模板，仅影片名不同）

253期李太阳福彩3D预测奖号：直选推荐  ↔  253期钱哥福彩3D预测奖号：组六推荐
```

**量化**：去重后 2576 条标题中，模板化标题 **218 条（8.5%）**：

| 模板 | 条数 | 占比 |
| --- | --- | --- |
| 微博观影团抢票 | 24 | 0.9% |
| 彩票预测类（双色球/福彩3D/大乐透/排列） | 101 | 3.9% |
| 竞彩/指数类 | 40 | 1.6% |
| 影迷评 | 29 | 1.1% |
| 公司增持/减持 | 25 | 1.0% |

**含义**：只占 8.5% 的模板内容，却占据了相似度最高的位置——因为模板文本的
TF-IDF 向量几乎相同。这既是「TF-IDF + 余弦对模板/机器生成内容极敏感」的实证
（可用于识别低质批量内容），也说明**若直接拿 Top-10 当“新闻事件重复”来解读会严重误判**。

### 3.2 相似度=1.0 不等于语义相同（词袋的固有局限）

修正后仍有 `1.0000` 的文本对，但它们**语义不同**：

```
109期张世奇双色球预测奖号：大小比参考  ↔  109期林必立双色球预测奖号：大小比参考
[小炮APP]专家齐大力竞彩推荐：日职+德甲2串1  ↔  [小炮APP]专家齐大力竞彩推荐：意甲西甲2串1
```

人名、期号、联赛这些**关键差异信息**在分词后全部落入被过滤的 token
（纯数字被规则过滤、专有名词未进 `max_features=1000`），于是向量完全一致。
这正是词袋模型的固有天花板，也是实验二引入词向量的动机。
